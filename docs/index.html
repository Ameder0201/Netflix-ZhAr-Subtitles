导入显示 Not Found？

先点击「复制模块链接」，在 Shadowrocket「配置 → 模块 → 添加」中粘贴。当前主入口为直接下载地址；若仍失败，可尝试卡片中的备用下载。请在 Safari 打开本安装页再使用一键按钮。

首次安装

  1. 准备 HTTPS 解密。在目标设备的 Shadowrocket 开启解密，按客户端步骤安装并信任其证书。模块会追加 Netflix 字幕 CDN 域名；不会替你安装证书。
  2. 选择一个翻译模块。Google 与 DeepL 二选一，同时停用其他 Netflix 翻译、实验和维护模块。Universal 如果用于其他平台，可保持原状；本项目自身不依赖它。
  3. DeepL 填写参数。在模块「编辑参数」填写自己的 DeepLKey，DeepLPlan 选 Free 或 Pro。密钥占位值不会触发翻译请求。不需要在本网页输入密钥。
  4. 播放并检查。选择影片已有的文字字幕。默认 AUTO 将同一原文分别译成简体中文与阿拉伯语；中文在上。以后在模块上点击更新即可。

Apple TV 如何安装？

一键按钮打开的是当前设备的 Shadowrocket，不会远程安装到 Apple TV。请复制上方固定链接，在 Apple TV 的 Shadowrocket「配置 → 模块 → 添加」中导入。

tvOS 若没有「编辑参数」入口，可继续使用已有的本地私有配置服务生成 DeepL 包；不要把带密钥的个人包上传到公开仓库。已有用户正在使用的私有入口不受本次公开发布影响。

支持范围、验证状态与参数

语言显示和容量修复核心已在 Apple TV 获得用户播放反馈。公开包新增的原生参数入口已通过本地模拟测试，仍需在具体 Shadowrocket／tvOS 版本上验证；首次安装后应确认双语、拖动和连接稳定性。

本版面向带 SegmentIndex 的 WebVTT，保持原段长度与精确 206。超限时精简元数据，再使用简洁布局；仍放不下则保留原字幕。未实现跨请求字幕缓存，重复加载同一段可能再次调用接口。并非所有字幕格式、影片和任意 Range 都受支持。

SourceLanguage
AUTO、ZH-HANS、ZH-HANT、EN 等；这里指字幕语言。
Position
zh-first（中文在上）或 ar-first。
Pipeline
direct：同一原文分别译成两种语言；pivot-zh：先译中文，再由中文译阿语。
DeepLPlan / DeepLKey
DeepL 模块专用；Free／Pro 和你自己的 API key。
