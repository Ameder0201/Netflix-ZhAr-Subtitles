Google 旧版兼容模块

简体中文＋阿拉伯语。无需 API 密钥，无需编辑模块参数。

当前版本：ipad-compat-1 · 核心 v21-config-2

一键导入 Shadowrocket 查看／下载模块文件
  1. 在 iPad 的 Safari 打开此页，点击上方按钮，允许打开 Shadowrocket 并完成导入。
  2. 只启用「Netflix 中阿双语 · Google 旧版兼容」，停用原 Google、DeepL 和其他 Netflix 翻译模块。
  3. 保持 HTTPS 解密及证书信任，重新打开 Netflix，选择简体中文字幕测试。

后续更新：退出 Netflix，在 Shadowrocket 的「配置 → 模块」中对这份兼容模块点「更新」。固定地址不变，无需反复复制链接。

此入口绕过旧版客户端的参数替换。已通过本地模拟测试，iPad 实际翻译效果仍待验证；不包含 DeepL 密钥，也不会修改已有 DeepL 模块。
