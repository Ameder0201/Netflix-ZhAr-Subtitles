旧版 Shadowrocket 兼容模块

Google

简体中文＋阿拉伯语。无需 API 密钥，无需编辑模块参数。

当前版本：ipad-compat-1 · 核心 v21-config-2

一键导入 Google 兼容版 查看／下载模块文件
  1. 在 iPad 的 Safari 打开此页，点击上方按钮，允许打开 Shadowrocket 并完成导入。
  2. 只启用「Netflix 中阿双语 · Google 旧版兼容」，停用原 Google、DeepL 和其他 Netflix 翻译模块。
  3. 保持 HTTPS 解密及证书信任，重新打开 Netflix，选择简体中文字幕测试。

后续更新：退出 Netflix，在 Shadowrocket 的「配置 → 模块」中对这份兼容模块点「更新」。固定地址不变，无需反复复制链接。

2026-10-30，用户确认 iPad／Shadowrocket 2.2.24 使用 Google 兼容版已能翻译。此结果不代表所有影片、拖动或长期稳定性均已验证。

DeepL API

同样显示简体中文＋阿拉伯语，使用自己的 DeepL API 密钥。固定 AUTO／direct／中文在上，不使用模块参数模板。

当前版本：ipad-deepl-compat-1 · 核心 v21-config-2 · 本地模拟通过，iPad 实机待验证

一键导入 DeepL 兼容版 查看／下载 DeepL 兼容模块
  1. 导入后打开这份模块的源码编辑页，找到 [Script] 下那一长行的末尾：
    argument=DeepLPlan=Free&DeepLKey=REPLACE_WITH_YOUR_KEY
  2. 只把 REPLACE_WITH_YOUR_KEY 换成完整 API 密钥，保留 DeepLKey=；Free 密钥的 :fx 后缀也需保留。使用 DeepL API Pro 时将 DeepLPlan=Free 改为 DeepLPlan=Pro。保存，不需要寻找「编辑参数」入口。
  3. 停用 Google 兼容版及其他 Netflix 翻译模块，只启用「Netflix 中阿双语 · DeepL 旧版兼容」，重新打开 Netflix 测试。

DeepL 更新：仍可对同一份模块点更新，但远程模块只有密钥占位值，更新可能覆盖本地修改；更新后检查并重新填写密钥。网页不接收或保存密钥，脚本不写设备缓存。

Google 完全不依赖原生参数；DeepL 仍需客户端传递普通脚本 argument，兼容字符串、JSON 字符串及对象形式。若旧客户端完全不传 argument，此版会保留原字幕并记录缺少密钥，不能保证仅靠导入即恢复。
